# Bhargava Institute

A responsive React + Vite teaching website MVP.

## Run locally

Requirements:
- Node.js 18+ (Node.js 20+ recommended)
- npm

Commands:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually http://localhost:5173

## Build

```bash
npm run build
```

The production files will be generated in `dist/`.

## Included
- Home
- Courses
- Course details
- Subjects
- Quiz with score
- Study Material
- About
- Contact form demo
- Responsive mobile/desktop design
- Bootstrap + Bootstrap Icons
